# Effects

Sidebar **Effects** lists one-shot buttons next to the Designer stage. Click a button to fire it on the overlay and preview it on the stage. The wrench opens that effect’s edit panel: name, animation, duration, easing, tint, strength (sliders with reset), and save/delete preset. **Add effect** is at the bottom of the list.

Systray **Effects** opens a second Designer window on this tab (`/control`).
